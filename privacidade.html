Política de Privacidade do Sentinela

Última atualização: 07/11/2026

O Sentinela guarda só o necessário para funcionar no seu servidor e para cobrar os planos, seguindo a Lei Geral de Proteção de Dados (LGPD).

O Sentinela lê as mensagens dos servidores só para contar XP e detectar spam e flood. O texto das mensagens não é guardado para isso.

Também guardamos: o motivo escrito nas advertências, as inscrições e os ganhadores de sorteios e quem usou cada código promocional. Não guardamos endereço IP.

Não guardamos dados de cartão: eles ficam com o Mercado Pago.

3. Base legal

  • Execução do contrato: para entregar o plano contratado e cobrar.
  • Legítimo interesse: para as funções que os administradores do servidor ligam (níveis, logs, proteção).
  • Cumprimento de obrigação legal: para guardar registros de pagamento pelo prazo que a lei exige.

4. Com quem compartilhamos

  • Discord: a plataforma onde o bot funciona.
  • Mercado Pago: processa os pagamentos.
  • Provedores de infraestrutura: servidor em nuvem onde o bot roda, rede que protege o site e armazenamento dos backups.

Não vendemos dados e não usamos dados para publicidade.

5. Por quanto tempo

  • Dados de um servidor ficam enquanto o Sentinela estiver nele. Quando o bot sai, os dados do servidor são apagados 90 dias depois (se o bot voltar antes disso, eles continuam).
  • Dados apagados podem continuar nas cópias de segurança (backups) por até 90 dias, até essas cópias serem substituídas. Inscrições de sorteios encerrados ficam 180 dias.
  • Registros de pagamento ficam pelo prazo exigido pela lei fiscal.

6. Seus direitos

Você pode pedir para saber quais dados temos sobre você, corrigir, apagar ou levar seus dados (LGPD, art. 18). Para apagar seu XP ou suas advertências num servidor, use /sentinela_privacidade. Para o resto, peça pelo contato@botsentinela.com.br ou pelo suporte na Base Sentinela. Respondemos em até 15 dias.

7. Segurança

Os dados ficam num servidor com acesso restrito, com cópias de segurança criptografadas guardadas fora do servidor principal. Pagamentos são verificados com assinatura digital do Mercado Pago.

8. Menores de idade

O Sentinela segue a idade mínima do Discord. Planos pagos só podem ser contratados por maiores de 18 anos ou com autorização de um responsável.

9. Mudanças

Quando esta política mudar, a data no topo muda e as mudanças importantes são avisadas na Base Sentinela.

Veja também: Termos de Uso. Dúvidas: contato@botsentinela.com.br ou no servidor de suporte.
